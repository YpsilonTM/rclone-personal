# rclone-personal

Personal branding / privacy pages for a private **rclone** Google OAuth client
(Drive remotes for backups, sync, etc.).

Not a public product — exists so Google Auth Platform Branding has valid
homepage + privacy URLs.

## URLs for Google Cloud Branding

| Field | URL |
|-------|-----|
| App name | `rclone-personal` |
| Application home page | https://github.com/YpsilonTM/rclone-personal |
| Privacy policy | https://github.com/YpsilonTM/rclone-personal/blob/main/privacy.html |
| Authorised domain | `github.com` |

Optional later (GitHub Pages):

- https://ypsilontm.github.io/rclone-personal/
- https://ypsilontm.github.io/rclone-personal/privacy.html
- Authorised domain: `ypsilontm.github.io`

## Logo

`assets/logo.svg` — fine on the site. **Do not upload a logo in Google Auth
Branding** unless you want to trigger OAuth verification.
